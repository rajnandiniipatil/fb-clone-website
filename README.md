# fb-clone-website

This project is a **Facebook Clone Website** created as part of my Git and GitHub learning journey. The main purpose of this project was to practice building a web interface inspired by Facebook while improving my understanding of frontend development and version control using Git.

## 📌 About the Project

The Facebook Clone is a frontend-based website that recreates the basic look and feel of a social media platform. It includes a user-friendly layout inspired by Facebook, with sections such as a navigation bar, user profile area, posts/feed section, and other common social media UI elements.

I developed this project while following a **Git Tutorial**, which helped me understand how to create a repository, manage project files, make commits, track changes, and push my project to GitHub.

## 🚀 Features

- Facebook-inspired user interface
- Navigation bar and profile section
- Social media feed layout
- Post and content sections
- Responsive and clean webpage structure
- Simple and user-friendly design
- Organized project files
- Version control using Git and GitHub

## 🛠️ Technologies Used

- HTML
- CSS
- Git
- GitHub

## 🎯 Purpose of the Project

The main goal of this project was to gain practical experience in:

- Creating a website using HTML and CSS
- Designing a social media-style user interface
- Understanding website structure and layout
- Using Git for version control
- Creating and managing a GitHub repository
- Making commits and tracking changes
